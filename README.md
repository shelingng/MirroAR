## 🪞 Core Individual Project: MirroAR

A comprehensive user-centered smart mirror prototype built during my human-computer interaction and design coursework.

* **Project Overview:** MirroAR is an interactive, augmented reality (AR) smart mirror system engineered for automated outfit determination, hairstyle selection, and virtual styling visualization.
* **UX/UI Methodology:** Developed using strict user-centered design frameworks, featuring detailed user personas (ranging from freelance image stylists to university students), custom journey maps, and interactive high-fidelity Figma prototypes built around Gestalt principles.
* **Technical Engineering:** Modeled complete application life cycles, interaction rules, and system logic requirements using detailed requirement matrices, functional test cases (for authentication and core features), and structured PlantUML sequence diagrams.
